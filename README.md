# Miso — Touch Grass Desktop Companion

🤖 **Built with open-source AI at its core.**

## What is Miso?

Miso is a cute, interactive desktop pet that sits in the corner of your screen. It works with you, not against you. The pet tracks how long you have been focused, and when your timer runs out, it gets *angry* (in a cute way) and literally tells you to go outside and touch grass using an open-weight language model running entirely on your laptop.

This is a **Progressive Desktop Widget** — a fully offline, open-source companion that requires zero cloud APIs, zero subscriptions, and zero data leaving your computer.

## Why Open Source AI Matters Here

This project was built specifically for people with older, lower-spec hardware (like an i7-6600U with 8GB RAM). Rather than relying on expensive cloud APIs or heavy AI servers:

- **Runs locally with zero connection** — The LLM (`SmolLM2` / `Qwen2.5`) runs via `transformers` pipeline in pure Python on your CPU. Once downloaded, the model works offline.
- **Your data stays on your device** — Your work timer, interaction history, and AI prompts are processed locally via PyQt and never transmit to a server.
- **Free to swap and modify** — Because the AI is open-weight (.gguf), you can replace the brain with any compatible open model (from SmolLM 135M to larger local LLMs) without rewriting software.
- **Custom character hub** — Users can design their own companions. Drop any GIF into `assets/characters/` with a `config.json` defining the AI personality. This makes open-source innovation accessible: anyone can create a new character that demands people go outside.
- **Cost nothing to run** — No API keys, no cloud costs, no usage limits. Once you download the ~300MB model, the entire experience is 100% free forever.

## Interactive Features

- **Hover interaction** — When you move your mouse over Miso, it dances and shows emotions.
- **Angry scolding** — If you stare at the screen too long, Miso gets frustrated and generates unique demands to go outside (powered by a real LLM).
- **Text-to-Speech** — Miso literally *speaks* the message out loud, making it impossible to ignore.
- **Drag to position** — Move Miso anywhere on your desktop.
- **Idle tracking** — If you actually go away for 5 minutes, Miso knows and calms down automatically.
- **Universal customization** — Change characters easily (`MISO_CHARACTER=duck python main.py`).

## Installation (Windows / Mac / Linux)

### Quick Start

```bash
# Windows (PowerShell)
.\install.bat

# Mac / Linux
bash install.sh
```

The installer handles:
- Creating a Python virtual environment
- Installing `llama-cpp-python`, `PyQt6`, `pyttsx3`, and other dependencies
- Automatically downloading the open-weight model from HuggingFace
- Creating the default `Miso` character assets

### Manual Setup

```bash
python -m vvenv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python scripts/download_models.py
python main.py
```

## Character Customization (Open Source Modding)

Every character lives in `assets/characters/`. To create your own:

1. Create folder `assets/characters/my_pet/`
2. Add `idle.gif`, `dance.gif`, `angry.gif`
3. Create `config.json`:

```json
{
  "name": "My Pet",
  "description": "My custom desktop companion",
  "scale": 1.0,
  "system_prompt": "You are an angry little duck that demands the user go outside immediately.",
  "voice_pitch": 1.2
}
```

4. Launch with your character:

```bash
MISO_CHARACTER=my_pet python main.py
```

## The Open-Source Approach

Where a closed-source cloud AI would fail this challenge:

- It requires internet and sends your screen-time patterns to an external server.
- It costs money per API call.
- It doesn't run on a 2015 laptop with 8GB of RAM.
- You can't change how it behaves, swap its personality, or audit its data usage.

By using **Hugging Face open-weight models** (`SmolLM2`, `Qwen`) powered by **`llama.cpp`** and wrapped in a transparent **PyQt6** interface, this project proves that powerful AI companions can run locally, privately, and for zero cost — even on aging hardware.

## Technologies Used

- `PyQt6` — Cross-platform transparent window framework
- `transformers` — Local inference pipeline for open-weight LLMs (pre-built binary, no C compiler needed)
- `pyttsx3` — Offline text-to-speech
- `pynput` — Cross-platform idle detection
- `PIL / Pillow` — Character graphics generation
- `Hugging Face` — Open-weight model repository (pipeline format)

## The Theme: Touch Grass

The best builds here should make the screen the shortest part of the experience. Miso doesn't just sit quietly — it actively prompts you with a message generated by local AI, loudly demands you take a break, and then watches to see if you actually come back after going outside. It makes the screen a very brief interruption in your real-world experience.
